# واجهة مساعد ذكي (شبيهة بـ ChatGPT)

- `index.html` — الواجهة كاملة بملف واحد (أبيض/أسود، فاتح وداكن، عربي RTL، ردود تتكتب تدريجياً، Markdown وكود مع زر نسخ، رفع ملفات وصور، إملاء صوتي وقراءة الرد بصوت، سجل محادثات).
- `server.py` — سيرفر محلي يربط الواجهة بالنموذج المدرب (`model.py`, `train.py`, `generate.py`).

## التشغيل
افتح `index.html` بالمتصفح، ومن **الإعدادات** اختر مصدر الردود:
1. **Claude (Anthropic API)**: ضع مفتاحك واسم الموديل. ردود حقيقية وتنزل تدريجياً.
2. **API متوافق مع OpenAI**: الرابط والمفتاح واسم الموديل.
3. **نموذجي المحلي**: `python train.py data.txt 4000 && python server.py` (نموذج صغير يكمل نصوص مثل بياناته، مو مساعد محادثة).

المفاتيح تنحفظ بمتصفحك فقط.
