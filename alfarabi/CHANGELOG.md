# سجل تحديثات تطبيق وموقع ثانوية الفارابي

## v2.7 (2026-11-09)
أساس هذا الإصدار: نسخة v2.6 المرفوعة (`base.apk`) — كل ملفاتها نُقلت إلى `alfarabi/www` (ملفات الواجهة) ثم أُضيفت التحديثات التالية.

### الواجهة
- **القائمة الرئيسية:** بالتصميم الملوّن (أيقونات متدرجة). الصفحة الرئيسية فيها 5 فقط: الجدول الأسبوعي، الغيابات، الدرجات، التحاضير، المحادثات. باقي الأقسام في القائمة الجانبية.
- **صفحة المدرسة بتصميم فيسبوك:** غلاف، شعار دائري، اسم وعدد المتابعين، زر متابعة أسود ورسالة، تبويبات ومنشورات بيضاء.
- **القائمة الرئيسية بتصميم جديد لجميع الأدوار** (طالب، مدرس، ولي أمر، إدارة): أيقونات SVG ملونة بدل الأرقام، وترتيب الأقسام في مجموعات (الدراسة / التواصل والأدوات / الحساب والنظام). (`www/af-menu.js`)
- **مربعات الصفحة الرئيسية** تُبنى تلقائياً من قائمة كل دور بنفس الأيقونات.

### الإشعارات (أندرويد + الموقع)
- **الإعلان/الإشعار**: يصل للطلاب بعنوان «إشعار» ونصه. إذا عدّلته الإدارة يصل إشعار جديد «✏️ تم تعديل الإشعار».
- **التحضير**: يصل لطلاب الصف المحدد بعنوان «تحضير جديد» + عنوان التحضير ووصفه + **اسم المدرس** والمادة والصف.
- **الجدول المدرسي**: إشعار «الجدول المدرسي» عند نشر أو تحديث جدول الصف.
- **العطل والدوام**: إشعار عند تغيير حالة اليوم (عطلة / دوام).
- **تقييم المدرس للطالب**: إشعار للطالب وولي الأمر.
- **الإدارة** تستقبل إشعارات رسائل الدعم والإشعارات المهمة.
- فحص الإعلانات/التحاضير/الجدول صار كل ~12 ثانية بدل ~45.
- (موجودة أصلاً وبقيت) رسائل الكروب باسم المرسل واسم الكروب ونص الرسالة، «جاري الكتابة» باسم الشخص، رسائل الخاص للمدرس، المكالمات بنمط واتساب (شاشة اتصال كاملة مع رد/رفض).

### الإدارة
- **تعديل الإعلانات المدرسية** بعد نشرها (زر «تعديل» بجانب «حذف»).
- **تعديل الإشعارات المهمة** (للإدارة ولصاحب الإشعار).
